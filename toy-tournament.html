How I Built It

Player Input & UI Ownership

Each player controls their own lobby selections, with shared menus supporting the overall session.

How I built it

PlayerInputManager handles dynamic joining. Per-player MultiplayerEventSystems give each lobby card its own controls, while shared menus use a global EventSystem.

Camera & UI Presentation

Each minigame uses cameras and player interfaces suited to its gameplay.

How I built it

I configured player-follow, top-down, and multi-phase camera rigs, then integrated per-player UI and visibility so interfaces appear in the correct split-screen view.

Reusable Game Flow

A shared framework connects the lobby, minigames, and results into a complete session.

How I built it

A persistent Boot scene and GameFlowController coordinate additive minigame loading, sequencing, results, and returning to the lobby.
