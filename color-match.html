Rounds & Accuracy

The server manages target colors, timed rounds, and accuracy scoring.

How I built it

A server-side GameManager generates a random RGB target and controls the round timer. When a player submits or time runs out, the server compares their guess with the target and calculates an accuracy percentage. Client scripts display the round state and results.

Interactive UI

RGB controls, a live preview, and results make each guess easy to adjust and review.

How I built it

I connected the three RGB sliders to synced text fields with values from 0–255 and a live color preview. Modular scripts handle slider input, timer updates, and the results screen, which displays the target color, submitted color, and accuracy. I implemented the interface from Paige Martin’s layouts and visual design.

Saved Stats & Achievements

Persistent performance records and badges give players goals beyond a single round.

How I built it

Roblox DataStore saves and loads total games played, average accuracy, and average submission time for solo play. The Stats menu displays those records across sessions. A modular achievement manager checks reward conditions and awards badges, including the 100% accuracy badge.

My Role

I handled all scripting and systems design, connecting the round flow, interactive interface, scoring, and saved player stats.

  • Implemented RGB sliders with synced text fields and a live color preview.
  • Built timed rounds, submission logic, and server-side accuracy checks.
  • Implemented the results screen showing the target color, player color, and accuracy.
  • Integrated Roblox DataStore to save and load player stats.
  • Added achievement logic for rewards such as the 100% accuracy badge.
